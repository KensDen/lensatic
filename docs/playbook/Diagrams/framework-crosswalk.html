AI Security Framework Crosswalk

How the major frameworks fit together: govern, model the threats, select controls, harden & operate
These frameworks aren’t competitors; they’re layers. Governance standards sit on top, threat models tell you what to defend, control catalogs say what to implement, and hardening baselines make it real. Most pair explicitly with one another.
How they layer

② Model the threats

③ Select controls
Choose & specify auditable safeguards
CSA AI Controls Matrix (243 controls; 247 in v1.1) NIST 800-53 / CSF 2.0 ISO 42001 Annex controls
▾
④ Harden & operate
Implement the basics well; enforce Zero Trust
CIS Controls v8.1 + Benchmarks NIST SP 800-207 (Zero Trust)
