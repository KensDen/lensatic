Lensatic privacy policy

Effective: 30 Sep 2026

Lensatic runs entirely on your device. The app and the web page carry all of their content with them. Once open, the web page needs no connection, and a saved copy works offline.

Lensatic makes no network requests. Once the web page is open it loads no scripts, fonts, images or data from anywhere, and the app does not connect to the internet.

There is no account and nothing to sign in to.

Lensatic collects no personal data, usage data, identifiers or diagnostics, and stores or transmits none. The one thing the web page keeps is your theme choice (system, light or dark), saved in your browser's local storage on your device and never sent anywhere; the app keeps nothing and follows your device's light or dark setting.

Lensatic holds nothing about you, so there is nothing to retain or delete. Clearing this site's data in your browser removes the saved theme choice.

There are no third-party software development kits (SDKs), no analytics and no advertising.

In the web page and the app, the only outside links go to the public documents cited in Sources and to the source repository on GitHub; both also link to this policy and the support page. They open in your browser, under those sites' own privacy policies. This page and the support page also link to GitHub.

The web copy at https://kensden.github.io/lensatic/ is hosted by GitHub Pages. GitHub's documentation for GitHub Pages says it logs and stores the internet protocol (IP) address of each visitor for security purposes (https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection); see also the GitHub Privacy Statement (https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Lensatic itself collects nothing from those visits.

Questions about this policy: open an issue on the repository's GitHub issues page, https://github.com/kensden/lensatic/issues. Opening an issue needs a GitHub account, and issues are public. An issue you open stays on GitHub under GitHub's privacy statement; ask in the issue and it will be deleted.

The effective date is the date of the content release that built this page, so it moves with each release.
